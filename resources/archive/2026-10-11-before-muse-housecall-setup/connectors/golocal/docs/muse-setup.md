## Copy this into Muse

```text
Create a private custom connector named GoLocal Test using the integration documentation at https://camryn-mechanomorphic-ellis.ngrok-free.dev/integration.

It offers a Streamable HTTP MCP endpoint at https://camryn-mechanomorphic-ellis.ngrok-free.dev/mcp and equivalent REST tools documented at the integration URL. Use whichever your custom connector supports.

It requires an Authorization: Bearer credential. Ask me for the GoLocal agent key through your secure credentials input; keep it in your Secure Credentials Store. Do not ask for the operator token, Jobber credentials or the full .env file in chat.

Start by calling connector_status and show its backend and restrictions. If it is in demo mode, all providers, availability and bookings are simulated. Ask me to approve the exact simulated appointment before confirming it. Show a simulated confirmation as a simulation and report zero charged.

If it is in Jobber mode, use only the exposed account-read and test-client tools. A created client is not a booking. A real test-client write needs separate operator browser approval. If an operation is pending or unknown, report that state without retrying it under a new key.
```

When Muse asks securely, copy **only** the key from local `.data/muse-key.txt`. It was generated by `npm run access` and is ignored by Git. Never upload `.env`: it also contains operator and vendor secrets. Set consequential tools to require approval.

## Demo test prompt

```text
Using GoLocal Test, find the fictional plumbing diagnostic provider for ZIP 84101. Show its simulated appointment options, total charge and terms, then ask me before confirming one. After I approve, return its simulated booking ID, check the status, and ask me before cancelling it. Do not contact any real plumber or make a payment.
```

Success means Muse actually calls the endpoint, discovers tools, completes the simulated flow and returns the persisted booking ID. A generated skill or connector name alone does not establish success. The record returned by `get_booking_status` is the check.
