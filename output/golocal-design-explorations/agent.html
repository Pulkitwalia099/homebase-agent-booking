Quick start

server:         GoLocal Demo
transport:      Streamable HTTP
endpoint:       https://getgolocal.com/demo/mcp
authentication: none

Initialize MCP, list tools, then call connector_status.

Workflow

scope_request
  → search_providers
  → get_availability
  → prepare_booking
  → customer approval
  → confirm_booking
  → get_booking_status

Connection configuration

{
  "mcpServers": {
    "golocal-demo": {
      "url": "https://getgolocal.com/demo/mcp"
    }
  }
}

Scope and current availability

Public demo: fictional plumbers, example prices and appointments.
No actual service, supplier-account access or payment.
Execution currently depends on the pilot machine and tunnel.
Client-specific configuration formats vary.

Supplier-connected customer accounts use separate OAuth setup:
https://getgolocal.com/connectors?flow=pilot
